# جست‌وجوی هوشمند قرآن و ترتیب نزول آیات

این پروژه یک برنامهٔ دسکتاپ ویندوز برای جست‌وجوی واژه‌ها و عبارت‌ها در متن قرآن است. رابط کاربری با PySide6 ساخته شده و کاملاً آفلاین است؛ برنامه به مرورگر، وب‌سرور یا اتصال اینترنت نیاز ندارد.

اطلاعات ترتیب و سال نزول عمدتاً از جدول ۱۴ کتاب «سیر تحول قرآن» استخراج شده است. این جدول گروه‌های هم‌زمان آیات را بر اساس تحلیل آماری و شواهد تاریخی مرتب می‌کند.

## استفاده از نسخهٔ آمادهٔ ویندوز

فایل `dist\QuranSearch-Windows.zip` را در یک پوشه استخراج کنید و سپس فایل زیر را اجرا کنید:

```text
QuranSearch\QuranSearch.exe
```

برای استفاده از این فایل نیازی به نصب Python یا کتابخانه‌های پروژه نیست. فایل `QuranSearch.exe` با دوبار کلیک اجرا می‌شود. پوشهٔ `_internal` باید کنار آن باقی بماند؛ برای جابه‌جایی برنامه، کل پوشهٔ `QuranSearch` را جابه‌جا کنید.

این فایل در حال حاضر امضای دیجیتال تجاری ندارد؛ بنابراین ممکن است Windows SmartScreen در اولین اجرا نام ناشر را ناشناخته نمایش دهد. فقط نسخه‌ای را اجرا کنید که مستقیماً از منبع مورداعتماد دریافت کرده‌اید.

## امکانات

- رابط گرافیکی مستقل و راست‌به‌چپ، بدون مرورگر
- جست‌وجوی یک یا چند واژه در متن قرآن
- حالت `OR`: یافتن آیاتی که حداقل یکی از واژه‌ها را دارند
- حالت `AND`: یافتن آیاتی که همهٔ واژه‌ها را دارند
- حالت `PHRASE`: یافتن عبارت دقیق با همان ترتیب واژه‌ها
- یکسان‌سازی تفاوت‌های رایج نوشتاری عربی و فارسی
- نمایش متن کامل آیه در خود برنامه
- نمایش سوره، شمارهٔ آیه، گروه آیات، موضوع، سال نزول و ترتیب نزول
- مرتب‌سازی نتایج با کلیک روی عنوان ستون‌ها
- ذخیرهٔ نتایج در قالب Excel یا CSV
- اجرای کاملاً آفلاین

برای جداکردن چند واژه می‌توان از ویرگول فارسی (`،`) یا انگلیسی (`,`) استفاده کرد.

## اجرای برنامه از کد منبع

Python نسخهٔ 3.10 یا جدیدتر را نصب کنید و سپس در PowerShell اجرا کنید:

```powershell
python -m pip install -r requirements.txt
python app_search.py
```

## ساخت فایل مستقل EXE

وابستگی‌های ساخت را نصب کنید:

```powershell
python -m pip install -r requirements-build.txt
```

سپس اسکریپت ساخت را اجرا کنید:

```powershell
.\build_windows.ps1
```

این اسکریپت برای جلوگیری از ورود کتابخانه‌های نامرتبط به فایل اجرایی، محیط ساخت جداگانه‌ای در پوشهٔ `.build-venv` ایجاد می‌کند. وجود Python 3.13 فقط روی رایانه‌ای که فایل EXE را می‌سازد لازم است؛ کاربران نهایی به Python نیاز ندارند.

خروجی‌ها در مسیرهای زیر ساخته می‌شوند:

```text
dist\QuranSearch\QuranSearch.exe
dist\QuranSearch-Windows.zip
```

پیکربندی PyInstaller در `QuranSearch.spec` قرار دارد. متن قرآن نیز همراه برنامه بسته‌بندی می‌شود. نسخهٔ پوشه‌ای عمداً انتخاب شده است: شروع سریع‌تری دارد و نسبت به فایل‌های خوداستخراج‌شوندهٔ تک‌فایلی کمتر با هشدار کاذب آنتی‌ویروس روبه‌رو می‌شود. کاربران فقط فایل ZIP را استخراج و `QuranSearch.exe` را اجرا می‌کنند.

## اجرای آزمون‌ها


## فایل‌های اصلی

- `app_search.py`: رابط گرافیکی دسکتاپ و نقطهٔ شروع برنامه
- `app_core.py`: اجرای جست‌وجو، آماده‌سازی نتایج و خروجی Excel/CSV
- `search_software.py`: داده‌های ترتیب نزول، نرمال‌سازی متن و توابع جست‌وجو
- `quran-simple.txt`: متن قرآن مورد استفاده برای جست‌وجو
- `QuranSearch.spec`: تنظیمات تولید فایل مستقل ویندوز
- `build_windows.ps1`: فرمان سادهٔ ساخت فایل اجرایی
- `tests/`: آزمون‌های خودکار

## نکته دربارهٔ شماره‌گذاری آیات

شماره‌گذاری برخی آیات در کتاب «سیر تحول قرآن» با شماره‌گذاری متن `quran-simple.txt` یکسان نیست. همچنین کتاب گاهی یک آیه را به بخش‌هایی مانند «الف» و «ب» تقسیم می‌کند یا بخشی از یک آیه را متعلق به زمان دیگری می‌داند.

ساختار فعلی برنامه فقط شمارهٔ کامل آیه را نگه می‌دارد؛ بنابراین بعضی محدوده‌ها ممکن است با شماره‌گذاری متداول قرآن ناسازگار یا هم‌پوشان دیده شوند. اطلاعات سال و ترتیب نزول نیز نتیجهٔ روش آماری و تاریخی منبع هستند و نباید تاریخ‌گذاری قطعی تلقی شوند.
