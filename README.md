# جست‌وجوی هوشمند قرآن و ترتیب نزول آیات

این پروژه یک برنامهٔ تحت وب ساده با استفاده از Streamlit است که امکان جست‌وجوی کلمات و عبارت‌ها در متن قرآن را فراهم می‌کند. آیات پیدا‌شده با اطلاعات مربوط به موضوع، سال نزول و ترتیب تقریبی نزول نمایش داده می‌شوند.

اطلاعات ترتیب و سال نزول عمدتاً از جدول ۱۴ کتاب «سیر تحول قرآن» استخراج شده است. این جدول گروه‌های هم‌زمان آیات را بر اساس تحلیل آماری و شواهد تاریخی مرتب می‌کند.

## امکانات

- جست‌وجوی یک یا چند کلمه در متن قرآن
- پشتیبانی از حالت‌های `OR`، `AND` و `PHRASE`
- یکسان‌سازی برخی تفاوت‌های نوشتاری عربی و فارسی
- نمایش سوره، شمارهٔ آیه، گروه آیات، موضوع، سال نزول و ترتیب نزول
- مرتب‌سازی نتایج بر اساس ترتیب نزول
- ایجاد پیوند مستقیم به آیه در Quran.com
- ذخیرهٔ خودکار نتایج در قالب CSV و Excel

## حالت‌های جست‌وجو

- `OR`: آیاتی که حداقل یکی از کلمات واردشده را دارند.
- `AND`: آیاتی که همهٔ کلمات واردشده را دارند.
- `PHRASE`: آیاتی که عبارت واردشده را با همان ترتیب کلمات دارند.

برای جداکردن کلمات می‌توان از ویرگول فارسی (`،`) یا انگلیسی (`,`) استفاده کرد.

## فایل‌های اصلی

- `app_search.py`: رابط کاربری Streamlit، نمایش نتایج و ذخیرهٔ خروجی‌ها
- `search_software.py`: داده‌های ترتیب نزول، نرمال‌سازی متن و توابع جست‌وجو
- `quran-simple.txt`: متن قرآن مورد استفاده برای جست‌وجو
- `books/Seire_tahavvole_Quran_1.pdf`: منبع اصلی اطلاعات ترتیب و سال نزول
- `tests/`: آزمون‌های خودکار برنامه
- `outputs/`: نتایج ذخیره‌شدهٔ جست‌وجوها

## نصب برنامه برای کاربران تازه‌کار

### ۱. نصب Python

قبل از هر چیز باید Python روی رایانه نصب باشد. برای این پروژه استفاده از Python نسخهٔ 3.10 یا جدیدتر پیشنهاد می‌شود.

اگر Python را ندارید، آن را از وب‌سایت رسمی [python.org](https://www.python.org/downloads/) دریافت و نصب کنید. هنگام نصب در ویندوز، حتماً گزینهٔ **Add Python to PATH** را فعال کنید تا دستور `python` در ترمینال شناخته شود.

پس از نصب، PowerShell را باز کنید و دستور زیر را اجرا کنید:

```powershell
python --version
```

اگر شمارهٔ نسخه‌ای مانند `Python 3.12.4` نمایش داده شد، Python درست نصب شده است. اگر دستور `python` شناخته نشد، PowerShell را ببندید و دوباره باز کنید یا Python را با گزینهٔ افزودن به PATH مجدداً نصب کنید.

### ۲. رفتن به پوشهٔ پروژه

در PowerShell با دستور `cd` وارد پوشهٔ پروژه شوید. برای نمونه:

```powershell
cd C:\my_files\Quran-sessions-bahrampour
```

### ۳. نصب کتابخانه‌های موردنیاز

فایل `requirements.txt` فهرست و نسخهٔ کتابخانه‌های لازم را در خود دارد. ابتدا ابزار نصب بسته‌ها را به‌روز کنید:

```powershell
python -m pip install --upgrade pip
```

سپس همهٔ وابستگی‌ها را با یک دستور نصب کنید:

```powershell
python -m pip install -r requirements.txt
```

این دستور Streamlit، pandas، کتابخانهٔ ساخت فایل Excel، ابزارهای پردازش متن عربی و کتابخانه‌های لازم برای آزمون‌ها را نصب می‌کند.

### ۴. اجرای برنامه

پس از پایان نصب، برنامه را اجرا کنید:

```powershell
python -m streamlit run app_search.py --server.port 8502
```

## اجرای برنامه

در اجراهای بعدی کافی است وارد پوشهٔ پروژه شوید و برنامه را اجرا کنید:

```powershell
python -m streamlit run app_search.py --server.port 8502
```

سپس نشانی نمایش‌داده‌شده در ترمینال، معمولاً آدرس زیر، را در مرورگر باز کنید:

```text
http://localhost:8502
```

### خطای دسترسی به پورت در ویندوز

پورت پیش‌فرض Streamlit برابر `8501` است. اگر ویندوز این پورت را رزرو کرده باشد، ممکن است خطای زیر نمایش داده شود:

```text
PermissionError: [WinError 10013] An attempt was made to access a socket
in a way forbidden by its access permissions
```

در این حالت برنامه را روی پورت دیگری مانند `8502` یا `8600` اجرا کنید:

```powershell
python -m streamlit run app_search.py --server.port 8600
```

برای بررسی پورت‌های رزروشده در ویندوز نیز می‌توان از دستور زیر استفاده کرد:

```powershell
netsh interface ipv4 show excludedportrange protocol=tcp
```

## روش استفاده

1. یک یا چند کلمهٔ عربی را در کادر جست‌وجو وارد کنید؛ برای مثال `انسان، ناس`.
2. حالت جست‌وجوی موردنظر را انتخاب کنید.
3. دکمهٔ «جستجو» را فشار دهید.
4. برای بازکردن متن آیه در Quran.com از پیوند ستون «مشاهده آیه» استفاده کنید.

## فایل‌های خروجی

پس از هر جست‌وجوی موفق، برنامه یک پوشهٔ زمان‌دار در مسیر `outputs/` ایجاد می‌کند و دو فایل زیر را در آن قرار می‌دهد:

```text
outputs/YYYYMMDD_HHMMSS/results.csv
outputs/YYYYMMDD_HHMMSS/results.xlsx
```

فایل CSV با کدگذاری `UTF-8 with BOM` ذخیره می‌شود تا متن فارسی در Excel درست نمایش داده شود.

## اجرای آزمون‌ها

برای اجرای همهٔ آزمون‌ها:

```powershell
python -m pytest -q
```

آزمون‌ها مواردی مانند نرمال‌سازی حروف عربی، حالت‌های مختلف جست‌وجو، ورودی خالی، نگاشت اطلاعات نزول و ساخت پیوند Quran.com را بررسی می‌کنند.

## نکتهٔ مهم دربارهٔ شماره‌گذاری آیات

شماره‌گذاری برخی آیات در کتاب «سیر تحول قرآن» با شماره‌گذاری متن `quran-simple.txt` یکسان نیست. علاوه بر آن، کتاب در مواردی یک آیه را به بخش‌هایی مانند «الف» و «ب» تقسیم می‌کند یا بخشی از یک آیه را متعلق به زمان دیگری می‌داند.

ساختار فعلی برنامه فقط شمارهٔ کامل آیه را نگهداری می‌کند؛ بنابراین بعضی محدوده‌ها ممکن است با شماره‌گذاری متداول قرآن ناسازگار یا هم‌پوشان دیده شوند. اطلاعات سال و ترتیب نزول نیز نتیجهٔ روش آماری و تاریخی منبع هستند و نباید آن‌ها را تاریخ‌گذاری قطعی تلقی کرد.
