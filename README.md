# جست‌وجوی هوشمند قرآن و ترتیب نزول آیات

برنامهٔ دسکتاپ ویندوز برای جست‌وجوی واژه‌ها و عبارت‌ها در متن قرآن. برنامه کاملاً آفلاین است و به مرورگر، اینترنت یا نصب Python نیاز ندارد.

## دانلود و اجرا

[⬇️ دانلود برنامه برای ویندوز](https://github.com/s110m/quran-revelation-search/releases/latest/download/QuranSearch-Windows.zip)

1. فایل بالا را دانلود کنید.
2. روی فایل ZIP راست‌کلیک و گزینهٔ **Extract All** را انتخاب کنید.
3. وارد پوشهٔ استخراج‌شده شوید.
4. روی `QuranSearch.exe` دوبار کلیک کنید.

پوشهٔ `_internal` باید کنار فایل اجرایی باقی بماند. برای جابه‌جایی برنامه، کل پوشهٔ `QuranSearch` را جابه‌جا کنید.

این فایل در حال حاضر امضای دیجیتال تجاری ندارد؛ بنابراین ممکن است Windows SmartScreen در اولین اجرا نام ناشر را ناشناخته نمایش دهد. فقط نسخه‌ای را اجرا کنید که مستقیماً از منبع مورداعتماد دریافت کرده‌اید.

## امکانات

- رابط گرافیکی مستقل و راست‌به‌چپ، بدون مرورگر
- جست‌وجوی یک یا چند واژه در متن قرآن
- حالت `OR`: یافتن آیاتی که حداقل یکی از واژه‌ها را دارند
- حالت `AND`: یافتن آیاتی که همهٔ واژه‌ها را دارند
- حالت `PHRASE`: یافتن عبارت دقیق با همان ترتیب واژه‌ها
- یکسان‌سازی تفاوت‌های رایج نوشتاری عربی و فارسی
- نمایش متن کامل آیه در خود برنامه
- نمایش سوره، شمارهٔ آیه، گروه آیات، موضوع، سال نزول و ترتیب نزول
- مرتب‌سازی نتایج با کلیک روی عنوان ستون‌ها
- ذخیرهٔ نتایج در قالب Excel یا CSV
- اجرای کاملاً آفلاین

برای جداکردن چند واژه می‌توان از ویرگول فارسی (`،`) یا انگلیسی (`,`) استفاده کرد.

## دربارهٔ اطلاعات ترتیب نزول

اطلاعات ترتیب و سال نزول عمدتاً از جدول ۱۴ کتاب «سیر تحول قرآن» استخراج شده است. این جدول گروه‌های هم‌زمان آیات را بر اساس تحلیل آماری و شواهد تاریخی مرتب می‌کند.

شماره‌گذاری برخی آیات در این کتاب با شماره‌گذاری متن برنامه یکسان نیست. همچنین کتاب گاهی یک آیه را به چند بخش تقسیم می‌کند یا بخشی از یک آیه را متعلق به زمان دیگری می‌داند. اطلاعات سال و ترتیب نزول نتیجهٔ روش آماری و تاریخی منبع هستند و نباید تاریخ‌گذاری قطعی تلقی شوند.

## برای توسعه‌دهندگان

کاربران عادی فقط به فایل ZIP بخش «دانلود و اجرا» نیاز دارند. فایل‌های Python، پوشهٔ کتاب‌ها و تنظیمات ساخت برای توسعه و بازسازی برنامه نگهداری می‌شوند.

اجرای برنامه از کد منبع:

```powershell
python -m pip install -r requirements.txt
python app_search.py
```

اجرای آزمون‌ها:

```powershell
python -m pip install -r requirements-build.txt
python -m pytest -q
```

ساخت بستهٔ ویندوز:

```powershell
.\build_windows.ps1
```

اسکریپت ساخت، محیط جداگانهٔ `.build-venv` را ایجاد می‌کند و خروجی نهایی را در `dist\QuranSearch-Windows.zip` قرار می‌دهد.
